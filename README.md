# Pokemon 2D RPG

> 학습 목적으로 제작한 포켓몬 스타일 2D RPG 클론 프로젝트입니다.  
> 턴제 전투와 상태 기반 시스템 구조를 이해하는 데 초점을 맞췄습니다.

---

## 프로젝트 개요

- **장르**: 2D 턴제 RPG
- **참고 게임**: Pokémon 시리즈
- **개발 목적**:  
  기존 게임의 전투 흐름과 상태 관리 구조를 분석하고  
  Unity 기반으로 구현하며 시스템 이해도를 높이기 위한 학습 프로젝트입니다.
- **개발 형태**: 개인 학습 프로젝트
- **엔진 / 언어**: Unity / C#

---

## 학습 목표

- 턴제 전투 시스템의 전체 흐름 이해
- 상태(State) 기반 캐릭터 행동 관리
- Scene 분리를 통한 게임 흐름 구조화

---

## 구현 내용

- 맵 이동 및 오브젝트 상호작용
- UI 기반 턴제 전투 흐름
- 플레이어 / 적 상태 관리
- 전투 종료 후 흐름 처리

---

## 배운 점

- 전투 시스템은 개별 기능보다  
  **전체 흐름과 상태 전이가 중요**하다는 점
- 상태 관리 방식에 따라  
  코드 가독성과 유지보수성이 크게 달라진다는 점
- Scene 분리를 통해  
  게임 흐름을 명확하게 유지할 수 있다는 점
